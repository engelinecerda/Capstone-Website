Cancellation Notice Rules

How much lead time a customer needs to cancel an existing reservation — separate from the Booking Notice Window above, which governs new bookings instead. Fees for cancelling live in Payment Settings.

Cancellation fee payment deadline

A cancellation request holds the reservation's date until the fee is paid and verified. If the deadline passes unpaid, the reservation is automatically finalized as cancelled and the date is released — the fee still stays owed.

Reschedule Policy

Rescheduling has no manager approval step — a customer picks any date the calendar shows open. These rules control the hold on that date while the fee is unpaid. The fee itself lives in Payment Settings.

Hold duration

How long the newly requested date stays reserved for this customer while they pay the reschedule fee, before it auto-releases back to the calendar.

hours

Minimum notice before original event

Customers must request a reschedule at least this many days before their currently-booked event date. Leave unchecked for no minimum.

days

Maximum reschedules per reservation

Caps how many times a single reservation can be rescheduled. A hold that expires unpaid doesn't count against this.

Extension Rules

A customer's request to add hours to an already-booked reservation holds that extra time on the calendar while the fee is unpaid, then requires Manager approval like any other payment. The per-hour rate is set per package in Packages ("Extension Price" — leave blank on a package to disable extensions for it).

Payment hold duration

How long the requested extra time stays reserved while the customer pays the extension fee, before it auto-releases back to the calendar. Extension holds are meant to be short — this is in minutes, not hours.
